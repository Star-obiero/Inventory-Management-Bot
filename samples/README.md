# Practice files

Send these to the bot as a **File**, with the caption `dry run` first.

| File | What it shows |
|---|---|
| `01_clean_import.csv` | Adds four new products, then changes their stock. Everything should go in. |
| `02_import_with_errors.csv` | Send after file 01. It has deliberate mistakes, so you can see how rejections look. |
| `03_excel_import.xlsx` | The same idea as file 01 in Excel, with different product names. |

Delete the test products from your stock sheet before using real stock.
